# Triage 标签

Skills 使用五种标准 Triage 角色。本文件负责将这些标准角色映射到本仓库问题跟踪系统中实际使用的标签名称。

| mattpocock/skills 标准标签 | 本仓库实际标签 | 含义 |
| -------------------------- | -------------- | ---- |
| `needs-triage` | `needs-triage` | 需要维护者评估此问题 |
| `needs-info` | `needs-info` | 正在等待提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已经完整，可以交给自动运行的 Agent |
| `ready-for-human` | `ready-for-human` | 需要由人类开发者实现或处理 |
| `wontfix` | `wontfix` | 不会处理此问题 |

当 Skill 提到某个角色时，例如“应用适合交给 Agent 的 Triage 标签”，应使用本表中对应的实际标签名称。

如果本仓库以后采用不同的标签命名规范，请修改表格中“本仓库实际标签”一列。
